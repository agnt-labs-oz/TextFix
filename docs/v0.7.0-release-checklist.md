## 1. GitHub Discussions setup

Required for the new tray-menu links ("Suggest a feature…" and "Report an issue…") added on the monetization branch to land somewhere.

1. Open https://github.com/agnt-labs-oz/TextFix/settings
2. Scroll to **Features** → tick **Discussions**.
3. Once enabled, go to https://github.com/agnt-labs-oz/TextFix/discussions
4. Click the **categories** gear icon (top-right of the categories list).
5. Create / verify these four categories:

   | Name | Format | Description |
   |---|---|---|
   | Ideas | Discussion | Feature requests and "wouldn't it be cool if…" |
   | Bugs | Open-ended | Quick-and-rough bug reports — bigger ones go to Issues |
   | Q&A | Question/Answer | Setup help, "how do I…" |
   | Show & Tell | Discussion | What you're using TextFix for |

6. Verify the structured Idea form renders by opening (in a private/incognito window):
   `https://github.com/agnt-labs-oz/TextFix/discussions/new?category=ideas`
   It should pull from `.github/DISCUSSION_TEMPLATE/ideas.yml` (added by the monetization branch).

7. While you're in repo Settings, also flick **Issues** on if it isn't already — `bug_report.yml` lives at `.github/ISSUE_TEMPLATE/`.

## 2. Screenshots

Referenced by the README rewrite on the monetization branch. Drop them into `docs/screenshots/` (create the folder if missing).

| Filename | What to capture |
|---|---|
| `overlay.png` | Overlay open with a real correction. Show the diff tab with red-strike + green-add highlighting. Crop to the overlay and a sliver of the surrounding app. |
| `api-key.png` | Anthropic console keys page (https://console.anthropic.com/settings/keys). **Mask the key** — blur or block out the `sk-ant-…` value before saving. |
| `settings.png` | TextFix Settings dialog, full window. Make sure the API key field shows masked dots. |
| `mode-picker.png` | Tray context menu open with the **Mode** submenu expanded. |

Optional but nice: a `tray.png` showing the tray icon + context menu after the new monetization items (Suggest a feature… / Report an issue… / Open log folder / About TextFix… / Support TextFix ☕).

**Capture tips on Windows 11:**
- `Win+Shift+S` to open Snipping Tool. Pick "Window" mode for clean dialog crops.
- For the tray menu, you can't capture a context menu with Snipping Tool because focus shifts. Workaround: use the timer in the full Snipping Tool app, set a 3 s delay, open the tray menu, wait for the snip to fire. Or use ShareX / Greenshot if installed.
- Save as PNG, not JPEG. Avoid screenshots wider than ~1600 px — large PNGs bloat the repo.

## 3. Tray-menu smoke test

After capturing screenshots and before merging:

1. Run `dotnet run --project src/TextFix/TextFix.csproj` from the **monetization worktree** (or the merged branch).
2. Right-click the tray icon. Click each new item and confirm the destination opens correctly:
   - **Suggest a feature…** → the Ideas Discussion form (the URL you verified above).
   - **Report an issue…** → the Bug Report Issue template.
   - **Open log folder** → Explorer opens at `%APPDATA%/TextFix/logs/`.
   - **About TextFix…** → the new `AboutWindow` opens with stats panel + Ko-fi CTA.
   - **Support TextFix ☕** → opens https://ko-fi.com/3smallwins in your default browser.
3. Also smoke-test the new items from the `feat/ui-polish-emoji` branch:
   - **Clear history…** → confirmation dialog appears, OK wipes the history submenu and the file at `%APPDATA%/TextFix/history.json`.
   - Settings → "Clear history now" button → same confirm + wipe behaviour.
   - Settings → "Recent corrections to keep" — try `5`, save, do six corrections, confirm only the most recent five appear in the History submenu.
4. Apply a correction. Try the new **▾ Collapse** button in the action row. Confirm the action row stays put while the diff above it disappears, and **▴ Expand** restores the previous height.
5. Apply a correction, then press **Enter** while the Corrected TextBox has focus → should dismiss (this was broken before today's fix and is the main reason this branch isn't already merged).
6. Cancel a correction (Esc) → focus should return to the source app (Notepad / VS Code / wherever you triggered from).

## 4. Merge + tag

Once 1–3 are clean:

```powershell
# from the main checkout (not the worktree)
git checkout master
git pull origin master

# bring in the UI polish branch
git merge --no-ff feat/ui-polish-emoji -m "Merge feat/ui-polish-emoji"
git push origin master

# bring in the monetization branch
git merge --no-ff feat/monetization-phase-1 -m "Merge feat/monetization-phase-1"
# resolve any conflicts (likely in App.xaml.cs around tray menu items, and possibly OverlayWindow.xaml.cs)
git push origin master

# tag and push — this triggers the GitHub Actions Velopack build
git tag v0.7.0
git push origin v0.7.0
```

Watch the run at https://github.com/agnt-labs-oz/TextFix/actions — it should produce `TextFix-v0.7.0-win-x64.zip` on a new GitHub Release.
